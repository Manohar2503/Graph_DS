# Graph_DS

A Java-based repository focused on implementing and understanding **Graph Data Structures and Algorithms**. This project contains graph representations, traversal techniques, and graph-related problem-solving programs useful for learning DSA and interview preparation.

---

## Features

- Graph Representation
  - Adjacency Matrix
  - Adjacency List
- Graph Traversal Algorithms
  - Breadth First Search (BFS)
  - Depth First Search (DFS)
- Graph Problem Implementations
- Beginner-friendly Java programs
- Well-structured source code for practice and learning

---

## Tech Stack

- **Language:** Java
- **IDE:** IntelliJ IDEA / Eclipse / VS Code
- **Concepts:** Data Structures & Algorithms (DSA)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Manohar2503/Graph_DS.git
```

### Navigate to Project Directory

```bash
cd Graph_DS
```

### Compile Java Files

```bash
javac filename.java
```

### Run the Program

```bash
java filename
```
